SpendWise AI 🚀
Optimize your team's AI subscriptions and save costs efficiently.
SpendWise AI is a smart audit tool designed to help companies and individuals reduce overhead on AI tool subscriptions like ChatGPT, Midjourney, and more. It provides data-driven recommendations to ensure you're using the most cost-effective plans.

✨ Features
Multi-Tool Support: Custom audit logic for ChatGPT, Midjourney, GitHub Copilot, and Cursor.
Real-time Analytics: Instant dashboard updates for monthly and annual savings projections.
Efficiency Score: A visual progress bar that calculates how well your current budget is being utilized.
Copy to Clipboard: Export your professional audit summary with a single click for easy sharing.

🛠️ Tech Stack
React.js - Frontend library for a dynamic user interface.
Tailwind CSS - For modern, responsive, and sleek styling.
Vite - High-performance build tool for fast development.
JavaScript (ES6+) - Core logic and calculation engine.

🚀 How to Run
Clone the repository:
git clone (https://github.com/ramteketrupti2604-creator/spend-wise)

Navigate to the project folder:
cd spend-wise

Install dependencies:
npm install

Start the development server:
npm run dev
